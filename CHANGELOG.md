# Changelog

Все заметные изменения проекта фиксируются здесь.

## Неизданное

### Добавлено
- Живой индикатор фоновых задач в шапке: пересборка памяти профилей и графы знаний видны из любого места интерфейса; бэкенд шлёт мгновенное событие старта переиндексации (раньше первый прогресс приходил лишь после целого батча — выглядело как зависание);
- Онбординг-тур новичка: карточка из 4 шагов при первом запуске (флаг в localStorage) и кнопка «?» в шапке для повторного показа;
- Дизайн-токены типографики --fs-meta/--fs-name/--fs-heading в :root: база × масштаб с системным полом читаемости, центральный блок мелких кеглей переведён на них;
- Живые обновления провайдеров: маркерные события providers_changed и settings_updated теперь перечитывают /api/providers — кастомные провайдеры и настройки применяются во всех вкладках без F5;
- Подтверждение доставки вопроса в чате («Вопрос доставлен участникам стола») и анонс завершения раунда с кратким итогом Хрономанта; удалён мёртвый обработчик report_failed;
- Читаемость на ноутбуках (14"): пол шрифта 9px для всех 40 мелких кеглей (6–8px), минимальная высота кнопок 24px, компактные отступы при высоте окна ≤800px;
- Экспорт траекторий в ShareGPT/messages JSONL (кнопка «⬇ JSONL») для fine-tuning и публикаций;
- Автопрепринт «постановка → метод → результаты» по протоколу сессии: пишется LLM памяти с ретраями, фолбэк на шаблон, сохраняется среди отчётов;
- Профилирование стоимости: таблица token_usage, оценка токенов на каждую реплику/реакцию/обзор, сводка GET /api/stats/tokens/{sessionId};
- Кросс-диалог: @упоминания агентов с приоритетом слова адресованному и подсветкой в чате, короткие реакции-перебивания между репликами (вероятность настраивается);
- настройки моделей внутри интерфейса: секция «Настройки системы» в drawer провайдеров — LLM памяти (endpoint/модель/ключ), реакции, тест соединения; хранение в БД, приоритет над env;
- Кнопка «♻️ Пересобрать память» в досье: дедупликация сырых записей и повторная экстракция сущностей с прогрессом;
- настраиваемый LLM для памяти (`MEMORY_LLM_BASE_URL/MODEL/API_KEY`) — экстракция больше не привязана к аккаунту Ollama и переживает его недоступность;

### Изменено
- LightRAG обновлён до 1.5.6; исправлен корневой баг памяти: эмбеддинг-функция возвращала список вместо numpy-массива, из-за чего каждая вставка падала (45/45 графов без сущностей);
- сбои записи памяти логируются вместо молчаливого проглатывания;
- экономия токенов: агент видит 12 свежих сообщений целиком (`AGENT_HISTORY_LIMIT`, было 48), RAG-контекст до 4000 символов, память до 2000 (`RAG_CONTEXT_LIMIT`/`MEMORY_CONTEXT_LIMIT`);
- Вкладка «Память» в досье Лаборатории: что персонаж помнит (сущности/связи профильного графа или сырые записи) и осознанный сброс «Забыть всё» с полным удалением графа;
- Оркестратор подбора моделей на данных Artificial Analysis: при создании персонажей кнопка `⚡ Подобрать модели` сверяет интеллект/скорость/цены из каталога AA (618+ моделей), пингует живых кандидатов и проставляет каждому герою оптимальную модель с учётом роли;
- drawer `Провайдеры`: статус источников, библиотека пресетов (DeepSeek, OpenRouter, Groq, Mistral, Together AI, xAI, Gemini OpenAI-совместимый, Fireworks, LM Studio) и добавление своих OpenAI-совместимых провайдеров;
- кастомные провайдеры хранятся в локальной БД (ключи маскируются в API), доступны во всех списках моделей, понимаются Хрономантом и оркестратором;
- REST: `/api/orchestrator/status|catalog|ping|recommend`, `/api/custom-providers[/presets|/{id}|{id}/test]`;
- Лаборатория персонажей (Фаза 1): досье с эволюцией показателей, ачивками и заметками Хрономанта;
- динамические бейджи тестов: CI публикует JSON на ветке `badges`, README читает их через shields.io endpoint;
- GitHub Actions CI: pytest (Windows) + vitest и production build (Ubuntu).

## v0.1.0 — 2026-04-06

### Добавлено
- комнаты, сессии и раунды для управляемых обсуждений;
- сохранение состояния в `SQLite`;
- инвентарь персонажей и скамейка участников;
- профессиональные роли и расширенные специализации;
- наблюдатель `Хрономант` с межраундовой аналитикой;
- пользовательские вопросы прямо в живой диалог;
- режимы `Бесконечный`, `С подсказками`, `Автофинал`;
- сценарии запуска и обслуживания через `start.bat`, `00_check_ollama.bat`, `01_prepare_ollama_models.bat`, `02_refresh_project_models.bat`;
- мягкое завершение dev-сеанса кнопкой `Завершить сеанс`;
- документация для handoff и журнал изменений;
- SVG и PNG ассеты для приложения, репозитория и релизов.

### Изменено
- по умолчанию быстрый cloud-дефолт переведён на `gemini-3-flash-preview:cloud`;
- интерфейс и сценарии запуска приведены к русскому стилю проекта;
- улучшен визуальный ритм реплик и появления пузырей;
- README репозитория оформлен в ретро-пиксельной эстетике проекта.

### Исправлено
- убрано дублирование сообщений в чате;
- исправлены повторные websocket-события через `event_id`;
- восстановление незавершённых сессий теперь переводит их в состояние `На паузе`;
- helper завершения dev-сеанса стабилизирован и проверен через dry-run.
